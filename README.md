# AI101

A free course for people starting from zero. By the last lesson you'll have an AI model running on your own computer, offline. No account, no subscription.

No sponsors, no affiliate links, nothing to buy.

Made by **ainarchy**, an open group of people who think everyone should be able to build with this technology, freely and for free. Questions, help and the lesson tasks live in our Telegram group: **https://t.me/ainarchyx** (room: BUILD).

## How it works

1. **Watch the lesson.** About ten minutes, on YouTube, with subtitles in nine languages. All lessons: [AI101 playlist](https://www.youtube.com/playlist?list=PLTRCPc39pKSI).
2. **Read the lesson's page here.** Tools in this field change every month, so the videos explain the ideas and this repository holds the exact steps. We keep it up to date.
3. **Do the small task in BUILD.** That's where the real learning happens: people helping people, at every level.

## What you need

- A computer. If it's from the last few years and has at least 8 GB of memory (RAM), it can very likely run a small model. Lesson 05 tells you exactly what fits yours.
- No coding, no expensive graphics card, no money.
- A phone or tablet is enough for Part 1. The hands-on lessons need a computer.

## How we make it

- **Zero assumed knowledge.** Every word is explained the first time it appears, and goes into the [glossary](GLOSSARY.md).
- **Non-directive.** When we use a tool we say why, and show at least one alternative. No "best model" claims.
- **Honest about limits.** What a model on your laptop can and can't do, compared with the big cloud services.
- **Tested before recorded.** Every hands-on step is run on a clean machine first. Windows first, with notes for macOS and Linux.
- **Safety first.** Trusted sources, safe file formats, licences, and never pasting a command you don't understand.
- **Sourced.** Every claim in a lesson has a source, listed on the lesson's page.
